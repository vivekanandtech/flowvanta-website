How to get a Loom embed ID:
  1. Open your Loom video
  2. Click Share → Copy embed code
  3. The ID is the string after /embed/ in the URL
     e.g. https://www.loom.com/embed/abc123def456  →  abc123def456
  4. Replace the placeholder text in index.html with that ID
  5. Uncomment the <iframe> block and delete the <div class="loom-placeholder"> block above it
