How to Automate Your Sales CRM with n8n and HubSpot

Flowvanta Engineering
June 2026 10 min read

Most sales teams are spending hours every week doing work that software should handle — copying leads from contact forms into HubSpot, manually updating deal stages, sending follow-up emails one by one. n8n eliminates all of it.

This guide walks through building a complete n8n → HubSpot CRM automation: auto-creating contacts, enriching them, scoring leads, and triggering personalised follow-up sequences — without writing a line of code.

What you'll build

A 6-node workflow that captures form submissions, creates/updates HubSpot contacts, scores the lead, assigns to the right rep, and triggers an automated follow-up sequence. All in under 2 seconds.

Step 1 — Set Up Your Trigger

1

Webhook or HubSpot Form trigger

Add a Webhook node as your trigger. This single URL accepts submissions from any form tool — Typeform, Tally, your own HTML form, or even a Zapier webhook if you're migrating. Set the method to POST.

If you're using HubSpot forms natively, use the HubSpot Trigger node instead — set it to fire on "New Form Submission." Connect your HubSpot account via OAuth in the credentials panel.

{
  "firstName": "Sarah",
  "lastName": "Chen",
  "email": "sarah@techstartup.io",
  "company": "TechStartup",
  "message": "We need to automate our onboarding workflow",
  "source": "website-contact-form"
}

Step 2 — Enrich the Lead

2

Add an HTTP Request node for enrichment

Connect an HTTP Request node to call a data enrichment API (Clearbit, Hunter.io, or Apollo.io). Pass the email from the previous node as a query parameter. This returns company size, industry, LinkedIn URL, and tech stack — automatically.

// HTTP Request node config
Method: GET
URL: https://company.clearbit.com/v2/companies/find
Query params:
  domain: {{ $json.email.split('@')[1] }}
Headers:
  Authorization: Bearer {{ $credentials.clearbitApiKey }}

If you don't have an enrichment API, skip to Step 3. You can always add enrichment later without rebuilding the workflow.

Step 3 — Score the Lead with AI

3

OpenAI node for intelligent lead scoring

Add an OpenAI node. Feed it the form submission and enrichment data. Ask it to classify the lead as Hot / Warm / Cold and assign a score from 1–10 based on your ideal customer profile.

// System prompt
You are a sales qualification assistant for a B2B automation agency.
Score this lead 1-10 and classify as Hot/Warm/Cold.

Ideal customer: B2B SaaS or agency, 10-200 employees,
mentions automation pain, has budget signals.

Return JSON: { "score": 8, "tier": "Hot", "reason": "..." }

// User prompt
Lead data: {{ JSON.stringify($json) }}

Step 4 — Create or Update the HubSpot Contact

4

HubSpot node — Upsert Contact

Add a HubSpot node set to "Create or Update Contact." Map the fields from your form submission and enrichment data. Add your AI lead score as a custom HubSpot property.

Key field mappings to set up in n8n:

  • email → Contact Email (used as the upsert key)
  • firstName, lastName → First Name, Last Name
  • company → Company Name
  • ai_lead_score → your custom HubSpot property
  • lead_source → "n8n Workflow Automation"
  • lifecyclestage → "lead"

Step 5 — Trigger the Right Follow-up Sequence

5

IF node → branch by lead tier

Add an IF node to branch your workflow based on the AI lead tier. Hot leads go to your fast-track sequence. Warm leads go to a nurture sequence. Cold leads are added to a newsletter list.

// IF node condition
{{ $json.tier }} equals "Hot"
  → true branch: enroll in Hot Lead Sequence
  → false branch: check Warm / Cold

For each branch, add a HubSpot node set to "Add Contact to Sequence." Select the appropriate sequence ID from the dropdown — n8n fetches these automatically from your HubSpot account.

Step 6 — Notify Your Sales Team on Slack

6

Slack node — instant sales alert

Add a Slack node on the Hot lead branch. Send a formatted message to your #sales channel with the contact details, lead score, and a direct link to the HubSpot contact. Your rep sees a new hot lead before they even check their email.

// Slack message template
🔥 *Hot Lead — Score {{ $json.score }}/10*

*Name:* {{ $json.firstName }} {{ $json.lastName }}
*Company:* {{ $json.company }}
*Email:* {{ $json.email }}
*Reason:* {{ $json.reason }}

<{{ $json.hubspotContactUrl }}|View in HubSpot>

Optimisations Worth Adding

Deduplication

Add a HubSpot node before Step 4 to search for existing contacts by email. If the contact exists, route to an "Update" branch instead of creating a duplicate. This keeps your CRM clean.

Deal creation for hot leads

On the Hot lead branch, add another HubSpot node set to "Create Deal." Automatically create a deal associated with the contact, set the deal stage to "Appointment Scheduled," and assign to the relevant rep based on territory or round-robin logic.

Error handling

Add an Error Trigger node as a global error handler. Route failures to a Slack #alerts channel with the full error payload. This way you never miss a lead because of a transient API failure.

Results from a real deployment

A SaaS client running this exact workflow went from a 4-hour average lead response time to under 2 minutes — for every inbound lead, 24/7. Hot leads were contacted before the prospect even left the website.

Common Questions

Do I need a paid HubSpot plan?

The basic contact creation and update operations work on HubSpot's free plan. Sequences and some workflow triggers require a paid Sales Hub plan. The Slack notification and lead scoring work regardless of your HubSpot tier.

Can I use this with Zoho or Salesforce instead of HubSpot?

Yes. n8n has native integrations for Zoho CRM, Salesforce, Pipedrive, and most other CRMs. The workflow logic stays identical — just swap the HubSpot nodes for your CRM's equivalent nodes.

How do I handle leads from multiple sources?

Create separate webhooks for each source (website form, LinkedIn ads, Typeform, etc.) and merge them into a single normalisation node that maps all fields to a standard schema before the enrichment step.
